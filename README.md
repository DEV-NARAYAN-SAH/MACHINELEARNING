Machine Learning (ML) is a subset of artificial intelligence (AI) that enables computers to learn and make decisions from data without being explicitly programmed.

Instead of following strict rules, ML systems find patterns in data and use those patterns to make predictions, detect anomalies, or automate tasks.

 Types of Machine Learning:
Supervised Learning

The model learns from labeled data (input + output).

Example: Predicting house prices, spam email detection.

Unsupervised Learning

The model learns from data without labels.

Example: Customer segmentation, topic modeling.

Reinforcement Learning

The model learns by interacting with an environment and receiving rewards.

Example: Game playing (like AlphaGo), self-driving cars.
